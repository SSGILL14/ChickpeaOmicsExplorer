# ChickpeaOmicsExplorer

ChickpeaOmicsExplorer integrates chickpea gene expression, functional annotations and co-expression networks to explore genes across tissues.

This repository contains the article's supplementary analysis code:

- **Methods S1.ipynb** — Expression preprocessing and classification, machine-learning benchmarks, GO enrichment and tissue-specificity plots.
- **Methods S2.R** — WGCNA co-expression analysis, module–tissue associations, hub genes and robustness checks.
- **Methods S3.ipynb** — Calculation of protein biochemical properties from peptide sequences.

Use the article's supplementary datasets as inputs and adjust file paths before running. Open the notebooks in Jupyter or Google Colab; run the R script with R.
